# Track 2 Dashboard 3D Visual References

These files preserve the approved A1 visual direction for the dashboard implementer.

- `a1-final-layout-detailed-racks.html` is the authoritative composition reference: industrial white/grey room, central aisle, two rack rows, floating evidence callout, and manual three-step navigation.
- `a1-modeling-clarity-target.html` is a detail study for rack construction: carbon-black frame, visible rails and U positions, brushed-silver GPU modules, vents, handles, labels, LEDs, contact shadows, and restrained status lighting.

The HTML files are brainstorming fragments rather than production components. Their amounts and node counts inside callouts are layout examples only. Production values must come from the generated TypeScript contracts and decision API.

The virtual room is a decision layout. The source data contains nodes but no physical rack coordinates, so the product must display `Decision layout — not physical rack location`.
